# Security Control Mapping & Traceability Matrix

> [!NOTE]
> This document maps each implemented security and DBMS control in the **Secure Banking System** to its objective, active implementation in [`bank/`](../bank/) and [`main.py`](../main.py), control category (*Preventive*, *Detective*, or *Corrective*), and backing automated tests in [`tests/`](../tests/). This is an educational prototype, not a compliance audit or certification.

---

| Control ID | Control Title | Control Objective | Implementation (File & Function) | Control Type | Automated Test Evidence |
|---|---|---|---|---|---|
| **CTL-01** | SQL Injection Defense | Prevent SQL injection by using parameterized queries (`?` / `%s`) across all SQL statements. | [`bank/db.py`](../bank/db.py), [`bank/transactions.py`](../bank/transactions.py), [`bank/auth.py`](../bank/auth.py) | **Preventive** | `tests/test_database.py::TestSchema` |
| **CTL-02** | Bcrypt Password Hashing | Protect stored credentials with salted adaptive `bcrypt` (`BCRYPT_ROUNDS = 12`) and constant-work dummy verification for unknown emails. | [`bank/auth.py`](../bank/auth.py): `hash_password()`, `verify_password()`, `DUMMY_PASSWORD_HASH` | **Preventive** | `tests/test_auth_login.py`, `tests/test_security_fixes.py::TestBcryptHashing` |
| **CTL-03** | Password Complexity Policy | Enforce minimum password strength (length >= 8, uppercase, lowercase, digit, special symbol) on password changes and demo seeding. | [`bank/security.py`](../bank/security.py): `password_meets_policy()` | **Preventive** | `tests/test_security_fixes.py::TestPasswordPolicy`, `tests/test_auth_login.py` |
| **CTL-04** | Brute-Force Lockout | Lock accounts atomically after 3 consecutive failed logins (`MAX_FAILED_LOGINS`), return generic failure errors, and raise one high-severity `"Brute Force"` alert. | [`bank/auth.py`](../bank/auth.py): `authenticate()`, `increment_failed_attempts()`, [`main.py`](../main.py): `login()` | **Preventive** | `tests/test_intrusion_and_unlock.py`, `tests/test_auth_login.py` |
| **CTL-05** | Decimal Amount Bounds Validation | Reject non-numeric, boolean, `NaN`, `Infinity`, `<= 0`, `> 2` decimal places, and `> MAX_AMOUNT` inputs via exact `Decimal` math plus SQL `CHECK` constraints. | [`bank/security.py`](../bank/security.py): `parse_money_input()`, `validate_amount()`, [`bank/db.py`](../bank/db.py) (`DECIMAL(12,2)`) | **Preventive** | `tests/test_decimal_money.py`, `tests/test_security_fixes.py::TestAmountValidation` |
| **CTL-06** | Safe CLI Input Wrappers | Handle malformed numeric CLI inputs gracefully without raising unhandled `ValueError` exceptions. | [`bank/security.py`](../bank/security.py): `safe_decimal_input()`, `safe_int_input()` | **Preventive** | `tests/test_security_fixes.py::TestSafeInputWrappers` |
| **CTL-07** | Session Inactivity Timeout | Enforce automatic logout after 300 seconds of inactivity using monotonic clocks. | [`bank/security.py`](../bank/security.py): `Session`, [`main.py`](../main.py): `menu()` | **Preventive** | `tests/test_security_fixes.py::TestSessionTimeout` |
| **CTL-08** | Data-Layer & CLI RBAC | Enforce ownership and admin-only permissions inside [`bank/`](../bank/) data functions as well as [`main.py`](../main.py). | [`bank/transactions.py`](../bank/transactions.py), [`bank/auth.py`](../bank/auth.py), [`bank/audit.py`](../bank/audit.py), [`bank/alerts.py`](../bank/alerts.py) | **Preventive** | `tests/test_rbac_data_layer.py` |
| **CTL-09** | Self-Transfer Restriction | Reject transfers where `from_account == to_account` in both [`main.py`](../main.py) and [`bank/transactions.py`](../bank/transactions.py). | [`main.py`](../main.py): `do_transfer()`, [`bank/transactions.py`](../bank/transactions.py): `transfer()`, `create_pending_transfer()` | **Preventive** | `tests/test_security_fixes.py::TestSelfTransferBlock` |
| **CTL-10** | Maker-Checker Dual Control | Queue transfers > `LARGE_TXN_THRESHOLD` (`Rs 50,000.00`) as `pending`, reserve funds, and block non-admins, makers, and recipient admins from approving. | [`bank/transactions.py`](../bank/transactions.py): `create_pending_transfer()`, `approve_pending_transfer()`, `reject_pending_transfer()` | **Preventive** | `tests/test_maker_checker.py`, `tests/test_rbac_data_layer.py` |
| **CTL-11** | Centralized Env Configuration | Store thresholds in [`bank/config.py`](../bank/config.py) and read DB credentials only from environment variables with zero default root credentials. | [`bank/config.py`](../bank/config.py), [`.env.example`](../.env.example) | **Preventive** | `tests/test_config_db.py`, `tests/test_cyber_controls.py::TestCentralizedConfiguration` |
| **CTL-12** | Atomic Transactions & Row Locking | Wrap financial updates, audit logs, and alerts in atomic write transactions (`BEGIN IMMEDIATE` on SQLite; `FOR UPDATE` in `account_id` order on MySQL). | [`bank/db.py`](../bank/db.py): `begin_write_transaction()`, [`bank/transactions.py`](../bank/transactions.py) | **Preventive** | `tests/test_atomic_transfers.py`, `tests/test_atomic_audit.py` |
| **CTL-13** | Cryptographic Audit Chain & SQL Triggers | Hash-chain `Audit_Log` entries via SHA-256 (`previous_hash`, `entry_hash`), fail closed on corruption, auto-log balance updates, and block `UPDATE`/`DELETE` via triggers. | [`bank/audit.py`](../bank/audit.py), [`bank/db.py`](../bank/db.py), [`sql/triggers.sql`](../sql/triggers.sql) | **Detective / Preventive** | `tests/test_audit_triggers.py`, `tests/test_atomic_audit.py` |
| **CTL-14** | Security Alerting | Raise atomic alerts for brute-force lockouts and large deposits/withdrawals/transfer requests (`> LARGE_TXN_THRESHOLD`), plus CLI velocity/tamper alerts. | [`bank/alerts.py`](../bank/alerts.py), [`bank/auth.py`](../bank/auth.py), [`bank/transactions.py`](../bank/transactions.py) | **Detective** | `tests/test_intrusion_and_unlock.py` |
| **CTL-15** | Admin Account Unlock | Allow administrators to unlock locked users (`is_locked = 0`, `failed_attempts = 0`) with audit logging. | [`bank/auth.py`](../bank/auth.py): `unlock_user()`, [`main.py`](../main.py): `manage_locked_users()` | **Corrective** | `tests/test_intrusion_and_unlock.py`, `tests/test_rbac_data_layer.py` |
| **CTL-16** | Alert Triage & SQLite Hot Backups | Provide admin alert triage (`open` -> `reviewed` -> `closed`) and checksum-verified hot SQLite backups/restores. | [`bank/alerts.py`](../bank/alerts.py), [`backup_restore.py`](../backup_restore.py) | **Corrective** | `tests/test_cyber_controls.py`, `tests/test_backup_restore.py` |
