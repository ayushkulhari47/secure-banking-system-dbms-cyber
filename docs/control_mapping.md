# ISO 27001:2022 Control Mapping & Traceability Matrix

> [!IMPORTANT]
> **Audit Note:** The control identifiers and clauses documented below reference the official **ISO/IEC 27001:2022 Annex A** control set (which consolidates information security controls into 93 controls across 4 organizational themes: *Organizational controls (Clause 5)*, *People controls (Clause 6)*, *Physical controls (Clause 7)*, and *Technological controls (Clause 8)*). Control numbers must be verified against the official ISO/IEC 27001:2022 standard in formal client audit engagements.

---

## 1. Overview & Scope
This document provides an IT Audit Risk & Control Matrix (RCM) for the **Secure Banking System**. It maps each system security control to its corresponding ISO/IEC 27001:2022 Annex A control objective, implementation location in source code, and classification (*Preventive*, *Detective*, or *Corrective*).

Every control listed in this document is backed by active source code in `db.py`, `security.py`, `config.py`, and `app.py` and validated by automated pytest test cases in `tests/`.
